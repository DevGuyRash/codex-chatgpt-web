# Reviewed Codex restart

Successful installation or approved repair opens a restart prompt, not clicking Reinstall or cancelling its review. **Later** leaves a persistent reminder. Automatic restart identifies one desktop application in the main process and requires explicit confirmation that active tasks are finished. The renderer supplies only an expiring opaque token; it cannot choose commands, paths, or process IDs. The runtime owner holds an idle drain across restart and resumes it afterward, including on failure. Work outside the bridge cannot be declared idle.

Linux automatic restart supports a narrow absolute-executable desktop entry whose local X11 windows match the executable and advertise `WM_DELETE_WINDOW`; it requests normal close through `wmctrl`. Wayland, custom wrappers, missing utilities, or ambiguous entries fall back to manual instructions. macOS identifies the `com.openai.codex` running application and requests normal termination through AppKit, then opens its observed bundle. Windows requires an OpenAI-signed Codex executable with a main window, requests `CloseMainWindow`, and relaunches that executable. Background processes, declined close, discovery failures, or failure to exit within 30 seconds are manual outcomes; no force-kill is used. Named CLI profiles retain manual session-restart guidance.

Process launch is not configuration verification. The reminder clears only after observed application-instance replacement and a subsequent successful model-catalog request. If the launcher lacks that evidence, the reminder remains. Restart-controller and native-adapter fixtures are not native Windows/macOS acceptance.

The platform contracts are documented by [Apple AppKit](https://developer.apple.com/documentation/appkit/nsrunningapplication?language=objc), [Microsoft CloseMainWindow](https://learn.microsoft.com/en-us/dotnet/api/system.diagnostics.process.closemainwindow), and the [Extended Window Manager Hints specification](https://specifications.freedesktop.org/wm/latest-single/). The user-facing confirmation follows the [Codex troubleshooting guidance](https://learn.chatgpt.com/docs/reference/troubleshooting) to finish active work before restarting.
