# Pinned libnotify build headers

These five unmodified libnotify 0.8.8 public headers are retained to reproduce the earlier reviewed runtime record. The current native build uses the pinned Debian sysroot's libnotify 0.7.9 headers directly and does not copy these files into it. The earlier build record contains their SHA-256 values. No libnotify library or user configuration is copied into the launcher.
